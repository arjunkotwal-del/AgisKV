Privacy policy

AegisKV runs locally by default. Prompts entered into the gateway sandbox are processed inside your local C++20 and FastAPI runtime.

Detected payment card numbers verified with Luhn mod-10, high-entropy API keys, and email addresses are redacted inside memory before any upstream model request or SQLite WAL trace write occurs. No third-party telemetry is collected unless upstream cloud credentials are explicitly configured via environment variables.
